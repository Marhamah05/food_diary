# Petunjuk cetak poster SHINING (A0)

| File | Kegunaan |
|---|---|
| **Poster_SHINING_A0_CETAK.pdf** | **Kirim file ini ke percetakan.** Semua teks sudah diubah menjadi kurva/vektor (tanpa font), jadi tidak bisa berubah huruf atau berantakan. |
| Poster_SHINING_A0.pdf | Versi biasa (font TrueType tertanam), bisa dicari teksnya. |
| Poster_SHINING_A0_150dpi.jpg | Cadangan gambar 4967 × 7022 px (150 dpi), jika percetakan meminta JPG. |
| Poster_SHINING_A0_preview.jpg | Pratinjau layar/HP, bukan untuk cetak. |

**Pesan untuk percetakan:**
- Ukuran **A0 (841 × 1189 mm)**, potret.
- Cetak **100% / ukuran sebenarnya**. Jangan pilih "fit to page".
- Tanpa bleed (latar sudah sampai tepi).
- Bahan disarankan: albatros/luster atau photo paper doff.
- Warna RGB. Minta proof kecil (A4) dulu bila ingin memastikan warna.
